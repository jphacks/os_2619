## 製品概要

### 背景(製品開発のきっかけ、課題等）

<!-- TODO: この節の考え方は、チーム（富本・拓海・チャオベン）で相談して確定させる -->

兵庫県朝来市生野町の山奥にある友達の家へ遊びに行ったとき、川原でかっこいい棒を拾った。拾った瞬間、誰に言われたわけでもなく、私たちはチャンバラを始めていた。棒を拾うと戦いたくなる。この少年心は、たぶん誰の中にもある。

ただ、頭の中で放っている炎や雷は、相手にも、見ている人にも見えない。楽しいのは本人たちの想像の中だけで、その瞬間は誰とも共有できずに消えてしまう。

私たちはこの「楽しい瞬間」そのものを価値にしたいと考えた。LLM の時代になり、言葉で処理できるものは AI が肩代わりできるようになった。論理で組み立てたプロダクトの多くは、「それ ChatGPT でよくない？」で片づいてしまう。反対に、言葉では評価できないもの、つまり体を動かして笑い合う時間の価値は上がっている。棒を振って魔法を撃ち合う楽しさは、まさにその種類のものだと考えている。

もう一つの課題は、手軽さである。気軽に遊びたいが、わざわざ外へ出かけたり、高価な機材をそろえたりはしたくない。家の中や教室でも、拾った棒と手持ちのスマホだけで遊べるレクリエーションが欲しかった。

### 製品説明（具体的な製品の説明）

FullStick は、拾った棒に小さなセンサーを付けるだけで、振った魔法が実際の空間に現れる対戦ゲームである。

<!-- TODO: 魔法が出ているプロジェクター画面の写真と、センサーを付けた棒の写真を貼る -->

- 棒の先に IMU（傾きと回転を測るセンサー）を付け、プレイヤーは胸にスマホを付ける
- 第三者視点のスマホで2人を撮ると、その映像に炎や雷の魔法が重なってプロジェクターに映る
- 棒を回すと魔法が溜まり、振ってピタッと止めると撃てる。溜めるほど強くなるが、溜めている間は動けない
- 当たり判定は3Dの位置で取るので、相手の魔法は実際に体を動かせば避けられる

遊び方は単純で、駆け引きがある。溜めずに撃つ「小」は弱いが連打でき、長く溜めた「大」は一発で形勢を変える。溜めている相手は無防備なので、潰しに行くか自分も溜めるかを、体を動かしながら選ぶことになる。

### 特長

#### 1. 拾った棒が、そのままコントローラーになる

専用のコントローラーはいらない。どんな形の棒でも、センサーをテープで巻き付ければ魔法の杖になる。棒の軸の向きは、棒を真上に向けてボタンを押すだけで合わせられる。

#### 2. 見ている人にも、同じ魔法が見える

VR のようにヘッドセットを付けた本人だけが見るのではなく、第三者視点の映像に魔法を重ねてプロジェクターに映す。戦っている2人も、周りで見ている人も、同じ魔法を見て盛り上がれる。

#### 3. 本物の空間で、体ごと戦う

3台のスマホと棒の位置を1つの3D空間にそろえているので、魔法は現実の位置から現実の位置へ飛ぶ。避けるボタンはなく、避けたければ実際に横へ動く。

### 解決出来ること

- 頭の中にしかなかった「魔法を撃ち合う楽しさ」を、相手とも観客とも共有できる形にする
- スマホと数千円のセンサー、印刷した紙のタグだけで、家の中や教室、学園祭の会場がそのまま遊び場になる
- 画面の前でじっとするゲームではなく、体を動かして笑い合う時間を手軽につくる

### 今後の展望

- 実機でのチューニング：棒の振り方の判定と、魔法が飛ぶ方向の合わせ込み
- 試合のあとに、見どころの場面を自由な視点で再生するリプレイ
- 属性を火・水・木の三すくみに広げ、属性ごとに溜めや攻撃の動きを変える
- 学園祭、地域のイベント、子ども向けの体験会での運用

### 注力したこと（こだわり等）

- **全員を1つの3D空間にそろえたこと。** 床や壁に置いた AprilTag（印刷する二次元マーカー）を、第三者視点のカメラと胸のスマホの両方が見て、カメラの位置・画角とスマホの位置を同じ座標に合わせる。合成データでは、スマホの位置のずれは 1cm 以内だった
- **「溜めるほど強いが無防備」というゲームの手触り。** 溜め時間で小・中・大が決まり、溜め中に 50cm 動くと溜めが消える。ダメージや溜め時間の区切りは、試遊しながらダッシュボードで変えられる
- **魔法を画像に頼らずコードで描いたこと。** 炎は PK ファイアー・ファイガ・爆炎、雷はサンダー・エルサンダー・かみなりを手本に、粒子・板・稲妻の線を組み合わせて描いた。カメラ映像はにじませず、魔法だけを光らせている
- **ハードがなくても開発を止めないこと。** 物理的に矛盾のない偽スマホと、台本どおりに棒を振る偽スマホを作り、ゲームの決まりは35本のシナリオで自動テストしている

## 開発技術

### 活用した技術

#### API・データ

- ARCore：胸のスマホの位置と向き（重力の向きにそろった座標）
- AprilTag（tag36h11）：フィールドの4枚と、胸の2枚のマーカー
- MediaPipe Pose Landmarker：第三者視点の映像から、プレイヤーの骨格を推定

#### フレームワーク・ライブラリ・モジュール

- Android（Kotlin）、OpenCV（aruco モジュールによる AprilTag の検出と姿勢推定）、OkHttp（WebSocket）
- Node.js、ws：スマホ3台とダッシュボードをつなぐサーバー（1つのポートで HTTP と HTTPS の両方を受ける）
- Three.js：3D 空間、魔法のエフェクト、プロジェクター用の映像
- js-aruco2：PC 側での AprilTag の検出
- WebRTC：第三者視点のスマホの映像を、遅延少なく PC へ送る（つながらないときは JPEG の連送に切り替える）
- Web Audio API：効果音と BGM

#### デバイス

- WitMotion WT9011DCL（Bluetooth LE の IMU）× 2：棒に付ける
- Android スマホ × 2：胸に付ける
- スマホ × 1：第三者視点のカメラ（ブラウザだけで動く）
- PC とプロジェクター

### 独自技術

#### ハッカソンで開発した独自機能・技術

- **AprilTag によるカメラとフィールドの自動計測。** 置いたタグを撮るだけで、フィールドの形・カメラの位置・画角・タグの傾きをまとめて求める（[fieldmap.js](product/dashboard/public/fieldmap.js)、[d76a952](https://github.com/jphacks/os_2619/commit/d76a952)、[189739b](https://github.com/jphacks/os_2619/commit/189739b)）
- **胸のスマホの座標合わせ。** 各スマホの ARCore の座標を、そのスマホが見たタグからフィールドの座標に重ねる（[phonealign.js](product/dashboard/public/phonealign.js)、[39e0388](https://github.com/jphacks/os_2619/commit/39e0388)）
- **棒の動作判定。** IMU から「棒を立てて回す（溜め）」「速く振って止める（発射）」を検知する（[actions.js](product/dashboard/public/actions.js)）
- **ゲームの決まりと、シナリオテスト。** 溜めの段階、溜め失敗、当たり判定、デモ試合のホーミング弾（[game.js](product/dashboard/public/game.js)、[test-game.mjs](product/dashboard/test-game.mjs)、[eec25c1](https://github.com/jphacks/os_2619/commit/eec25c1)、[c9fae47](https://github.com/jphacks/os_2619/commit/c9fae47)）
- **コードで描く魔法エフェクト。** 炎・雷の小中大と、溜め中のリミットチャージ・棒の先のスパーク風の球（[effects.js](product/dashboard/public/effects.js)、[fx-smash.js](product/dashboard/public/fx-smash.js)、[1290306](https://github.com/jphacks/os_2619/commit/1290306)）。画像素材を使う版も切り替えて使える（[f356330](https://github.com/jphacks/os_2619/commit/f356330)）
- **1つのサーバーで全部つなぐ仕組み。** スマホ A・B のセンサー中継、スマホ C の映像、証明書の発行を、ポート 8000 ひとつで受け持つ（[server.mjs](product/dashboard/server.mjs)、[a2f5626](https://github.com/jphacks/os_2619/commit/a2f5626)）
- **センサーアプリ。** WitMotion の IMU、ARCore、AprilTag の検出結果を LAN で PC に送る Android アプリ（[product/android](product/android)、[9d3c213](https://github.com/jphacks/os_2619/commit/9d3c213)）
