# チャージ中の実装

`product/dashboard/public/charge-effects.js` をHDR描画・ブルーム・映像合成へ接続しました。炎と電気のどちらも、溜めている間だけ全身オーラと杖先球を表示します。

## 表現

| 部位 | 表現 |
|---|---|
| 全身 | `aura-wisp.png` を胸の周囲へ立体的に配置し、足元付近から上へ流す。溜めが増えるほど本数、太さ、明るさが増える |
| 杖先の中心 | 3D球メッシュ。0秒付近では小さく、5秒で最大になる |
| 杖先の表面 | 炎は橙黄の `plasma-flow.png`、電気は黄白の `electric-filament.png` を球面上へ分散する |
| 杖先の外側 | 交差する3Dリング、短い火花、中心光。最大時は外向きの輪が周期的に広がる |

全身オーラはリミットチャージの縦に立つ光と上昇感、杖先球はスパークの球状輪郭と表面放電を参考にしています。画像一枚を体へ貼らず、各粒子と球・リングを3D位置に置くため、最終映像のカメラを動かしても立体配置が保たれます。

## 確認方法

`http://localhost:8000/?dummy#final` を再読み込みし、デモまたは試合中に次のキーを長押しします。

- `Q`: A（炎）のチャージ
- `P`: B（電気）のチャージ

キーを離すと、その時点の小・中・大に対応する攻撃を発射します。チャージしていない間の常時オーラは表示しません。

使用する5枚のPNGは `product/dashboard/public/assets/charge/` に原本と同じバイト列で配置しています。新しい画像生成は行わず、既存の透過素材を用途に合わせて実装しました。
