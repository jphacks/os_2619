# チャージ中の実装

`product/dashboard/public/charge-effects.js` をHDR描画・ブルーム・映像合成へ接続しました。炎と電気のどちらも、溜めている間だけ全身オーラと杖先球を表示します。

## 表現

| 部位 | 表現 |
|---|---|
| 全身 | 体の周りの円筒上に細い光の柱を立て、それぞれが上へ流れて消える（黄＋属性色）。脚の周りに揺らぎ（炎は `aura-wisp.png`、電気は `electric-filament.png`）、足元から広がる白い土煙、床の輪、体の後ろの淡い光。溜めが増えるほど本数・太さ・明るさが増え、満タンで脈動し床の輪が広がる |
| 杖先の中心 | 透ける3D球（明るい輪郭）と中の星。0秒付近では小さく、5秒で最大になる |
| 杖先の外側 | `spark-corona.png` の歯状のコロナ、外へ伸びるギザギザの稲妻（溜めると長い稲妻が増える）、表面を走る短い放電、周回する火花。最大時は輪が周期的に広がる |
| 色 | 炎は橙の球＋黄の稲妻、電気はスパークと同じ水色の球＋黄緑の稲妻 |

全身オーラはリミットチャージの縦に立つ光の柱・脚元の青い揺らぎ・土煙、杖先球はスパークの球の輪郭・歯状の縁・外へ伸びる稲妻を参考にしています。画像一枚を体へ貼らず、各粒子と球・リングを3D位置に置くため、最終映像のカメラを動かしても立体配置が保たれます。

## 確認方法

`http://localhost:8000/?dummy#final` を再読み込みし、デモまたは試合中に次のキーを長押しします。

- `A`: A（炎）のチャージ
- `B`: B（電気）のチャージ

キーを離すと、その時点の小・中・大に対応する攻撃を発射します。チャージしていない間の常時オーラは表示しません。

使用する9枚のPNGは `product/dashboard/public/assets/charge/` に原本と同じバイト列で配置しています。歯状のコロナ・星・ギザギザ・輪の4枚は `procedural/make-textures.mjs` で生成しています。

## プログラム版の溜めを属性ごとに作り分けた（2026-11-05）

プログラム版（`smash`）の溜めは `product/dashboard/public/fx-smash-charge.js` が描く。前は炎と雷が同じ光の柱を色違いで使っていた。大になった瞬間は白い光が広がり、4属性とも同じに見えていた。今回は、段階の出し方を4属性でそろえ、形は属性ごとに分けた。雷は黄色にした。

### 専門家が見る点

調べた資料から、溜めの演出で見る点を次のように整理した。

- 段階が読めること。小は足元だけ、中は体を上る、大は頭より高く出す。背の高さで段階がわかる
- 大の直前に「ため」を入れること。周りの粒を強く吸い込み、床の輪を足元へ縮める（約0.35秒）。そのあと解き放つ
- 大になった瞬間を、白い光で塗りつぶさないこと。属性の色の衝撃波を床に走らせ、光は0.1秒で消す。明るさの差が残るので形が見える
- 大を保っている間も危なく見せること。脈打ちを続け、約0.7秒ごとに小さな輪を床へ送る
- 属性の印は色より形で出すこと。炎は炎の輪と火の粉、雷は体を這う稲妻、水は水の帯と波紋、風は砂の渦と気圧の輪
- 明るい炎の横に暗い煙を置くこと。加算の光だけでは白く飛ぶので、覆う層（煙・水）で暗い所を作る
- 重ねる枚数を増やしすぎないこと。粒は大きく少なくし、描画の負荷を前と同じに保つ

### 属性ごとの見た目

| 属性 | 小 | 中 | 大になった瞬間 | 大を保つ間 |
|---|---|---|---|---|
| 炎 | 足元に炎の輪、暗い赤の床、火の粉が渦を巻いて寄る | 炎が体を上り、火花が飛ぶ | 炎の輪が噴き上がり、火の粉が飛び散り、黒い煙の輪が広がる | 胸まで届く炎、上へ走る熱い筋、頭上の黒い煙 |
| 雷（黄） | 体を這う稲妻2本、途切れる床の輪 | 稲妻4本、床を走る稲妻、稲妻の先で白く光る | 体を上る稲妻と床へ広がる稲妻 | 稲妻6〜7本、杖の先から床へ落ちる稲妻 |
| 水 | 膝までの水の帯、渦、波紋1本 | 腰より上の水の帯、波紋2本 | 水の王冠と水しぶき | 頭より上の水の帯3本、波紋3本、脈打つ |
| 風 | 腰までの風の帯2本、砂の渦 | 風の帯3本、木の葉が寄る | 速く細い気圧の輪、外へ走る空気の筋、砂と木の葉が飛ぶ | 風の帯4本、回る風の渦 |

杖の先も分けた。炎は稲妻をなくし、炎の球から炎の舌が立つ。雷は前と同じ、表面を稲妻が這う球にした。魔法陣（`fx-smash-circle.js`）は水だけに出す。ほかの属性は、それぞれの床の表現を持つ。

### 雷を黄色にした

雷の色を、昔のゲームの雷のように黄色にした。芯は白、稲妻は金色（#ffdb3d）、光は琥珀色（#ffb000）、火花は淡い黄色である。`effects.js` の `COL.elec`・`spark`・`elecGlow`・`white` を変えたので、弾、着弾、大の落雷、溜め、オーラ、ガードがすべて黄色になる。炎は橙と赤のまま残した。雷は緑が多く芯が白いので、炎とは色でも区別できる。形でも区別できる。素材の画像はもとから灰色なので、描き直していない。

### 押して溜めるボタンを直した

画面の「押して溜め」ボタンと Q・P キーでは、溜めが0.4秒しか伸びなかった。そのため小のまま止まり、約1秒で失敗していた。水と風が弱く見えたのは、このせいで小しか出ていなかったためでもある。押している間は0.2秒ごとに溜めを送り直すようにした。キーボード操作（`playable.js`）と同じ作りである。試合の規則は変えていない。

### 負荷

A と B の2人が大を溜めている間の、効果の層の GPU 時間を測った（M5、1280×720、ヘッドレスの Chromium、2回の平均）。

| 属性 | 前 | 後 |
|---|---|---|
| 炎 | 2.8 ms | 2.1 ms |
| 雷 | 2.2 ms | 2.1 ms |
| 水 | 2.0 ms | 2.1 ms |
| 風 | 2.6 ms | 2.4 ms |

測るたびに ±0.5 ms ほど揺れるので、増えも減りもしていないと見てよい。

### まだ足りない所

- 炎の陽炎（後ろの景色の揺らぎ）はない。効果の層が背景の映像を読まないためである
- 大を保つ間の雷は、炎よりおとなしく見える
- 床の輪は4属性とも細い線の輪で、形が似ている
