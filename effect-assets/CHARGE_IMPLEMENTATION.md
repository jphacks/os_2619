# チャージ中の実装

`product/dashboard/public/charge-effects.js` をHDR描画・ブルーム・映像合成へ接続しました。炎と電気のどちらも、溜めている間だけ全身オーラと杖先球を表示します。

## 表現

| 部位 | 表現 |
|---|---|
| 全身 | 体の周りの円筒上に細い光の柱を立て、それぞれが上へ流れて消える（黄＋属性色）。脚の周りに揺らぎ（炎は `aura-wisp.png`、電気は `electric-filament.png`）、足元から広がる白い土煙、床の輪、体の後ろの淡い光。溜めが増えるほど本数・太さ・明るさが増え、満タンで脈動し床の輪が広がる |
| 杖先の中心 | 透ける3D球（明るい輪郭）と中の星。0秒付近では小さく、5秒で最大になる |
| 杖先の外側 | `spark-corona.png` の歯状のコロナ、外へ伸びるギザギザの稲妻（溜めると長い稲妻が増える）、表面を走る短い放電、周回する火花。最大時は輪が周期的に広がる |
| 色 | 炎は橙の球＋黄の稲妻、電気はスパークと同じ水色の球＋黄緑の稲妻 |

全身オーラはリミットチャージの縦に立つ光の柱・脚元の青い揺らぎ・土煙、杖先球はスパークの球の輪郭・歯状の縁・外へ伸びる稲妻を参考にしています。画像一枚を体へ貼らず、各粒子と球・リングを3D位置に置くため、最終映像のカメラを動かしても立体配置が保たれます。

## 確認方法

`http://localhost:8000/?dummy#final` を再読み込みし、デモまたは試合中に次のキーを長押しします。

- `A`: A（炎）のチャージ
- `B`: B（電気）のチャージ

キーを離すと、その時点の小・中・大に対応する攻撃を発射します。チャージしていない間の常時オーラは表示しません。

使用する9枚のPNGは `product/dashboard/public/assets/charge/` に原本と同じバイト列で配置しています。歯状のコロナ・星・ギザギザ・輪の4枚は `procedural/make-textures.mjs` で生成しています。
