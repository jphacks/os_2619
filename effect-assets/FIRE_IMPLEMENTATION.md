# 炎の小・中・大の実装

`product/dashboard/public/fire-effects.js` を既存 `effects.js` のHDR描画・ブルーム・映像合成に接続しました。ゲーム画面と「4 最終映像」が同じ描画処理を使います。

## 参考を確認した結果

`reference/pkファイヤー.png`、`ファイガ.png`、`爆炎.png` と、SmashWiki掲載のUltimateのGIFをコマごとに確認しました。

| 段階 | 実装した見た目 | 参考 |
|---|---|---|
| 小 | 杖先から黄色く光るジグザグの立体弾（残像付き）。命中すると星形の閃光のあと、相手の膝あたりから頭上まで約1.9 mの火柱が立つ。白い芯・黄〜深紅の炎、上部から暗赤色の煙、周りを◆が漂い、約1.6秒で消える | [PK Fire](https://www.ssbwiki.com/PK_Fire) |
| 中 | ノイズで揺れる火球（白黄の芯）と、後方へ流れる炎の尾・火の粉。命中時は星形とギザギザの閃光、炎の塊が外へ飛び散り、相手に短く炎が残る | [Magic / Firaga](https://www.ssbwiki.com/Magic) |
| 大 | 小さな光から半径約0.95 mの炎の球が膨らむ。明るい輪郭、暗い赤の渦を巻く内部、外周の炎、中心の大きな星形フレア。約1秒保持したあと破裂し、炎の塊・火の粉・黒煙になる | [Explosive Flame](https://www.ssbwiki.com/Explosive_Flame) |

`textures/fire-lobe-v2.png` は、ファイガ・爆炎のreferenceを色と明るさの参考として内蔵生成ツールで新規生成しました。生成指示は `fire-generation.json` に記録しています。星形フレア・ギザギザの閃光・◆・輪は `procedural/make-textures.mjs` で生成しています。

## 使い方

サーバーとダミー送信が起動した状態で `http://localhost:8000/?dummy#final` を開き、ページを再読み込みしてください。

- 下部の「炎 小」「炎 中」「炎 大」でHPを変えずに演出を確認できます。
- 「炎を停止」「炎を1コマ進める」は確認用演出だけを操作します。センサー入力や試合全体を停止する機能ではありません。
- 「A → B」「B → A」で確認方向を選べます。小・中は発射側の杖先から相手へ飛び、大は相手の胸位置で爆発します。ダミー入力時の小・中は、移動する相手へ追従して着弾します。停止中は弾と着弾位置を固定します。
- ダミー映像では、その映像が持つ正確なカメラ姿勢と、描いた人物・杖の座標を合成に使います。人物座標は外部fake-world受信時と内部の自動生成時の両方に対応しています。ダミーの描画キャンバスを直接背景に使い、映像と座標のフレーム遅延を避けます。実カメラ映像では従来どおりタグのスキャン結果を使います。
- 実際の炎攻撃も新しい描画処理に接続済みです。溜めなしは小、2秒から中、5秒で大になります。電気も専用処理へ移行済みです。

今回の変更は炎の見た目と段階の接続です。試合時間・ダメージ値・大技の既存の命中判定など、ゲームルール全体の更新は含みません。

## 実装上の範囲

粒子は3D位置に分散し、球・弾・輪は3Dメッシュとして保持します。確認用演出はイベントの経過時間と固定の粒子番号で状態を求めるので、停止・コマ送りで形を固定できます。試合全体のリプレイ保存機能は未実装です。

カメラ映像は背景画像として合成します。実写人物の前後を判別する深度や人物マスクは今回追加していません。既存エフェクトレイヤーと同様、映像中の物体による遮蔽は行いません。

コードの構文、既存の `npm test`、追加した段階境界・確認用タイムライン・PNG配信のチェックを実行しました。実画面の見た目はユーザーが確認する予定です。
