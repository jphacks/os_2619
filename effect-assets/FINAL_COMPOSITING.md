# 4. 最終映像の合成

最終映像は、スマホ C の実写フレームを背景としてそのまま表示し、エフェクトだけを重ねます。人物、棒、フィールド、骨格、デバッグ用の3Dモデルは本映像へ描画しません。ダミー映像の人物も実写に写っている人物の代用であり、3Dモデルとして再描画しません。

投影に使う情報は、胸スマホのセンサーから求めたプレイヤー・杖先・攻撃の3D座標と、AprilTagスキャンで固定したスマホ C の位置・向き・画角です。合成順は次のとおりです。

1. 実写フレームを背景へ描画
2. センサー座標のエフェクトをカメラ姿勢と画角で投影
3. エフェクトのブルームを加算

最終映像下部の炎・電気・チャージ操作は表示確認専用です。Aキーで炎、Bキーで電気をチャージし、キーを離した瞬間に発射します。2秒未満は小、2秒以上5秒未満は中、5秒以上は大のエフェクトになります。既存の小・中・大ボタンでは各段階を直接確認できます。試合状態、HP、命中判定には影響しません。

最終映像固有の操作は `product/dashboard/public/final-controls.js` にまとめています。共通の `app.js` は初期化とフレームごとの呼び出しだけを担当します。
